## CS Master's student @ UNCW | Cybersecurity & Machine Learning

I'm a Computer Science graduate student at UNC Wilmington (B.S. in CS with a Security concentration, minor in Cybersecurity) with hands-on experience in binary analysis, malware obfuscation, and full-stack web development.

My work spans the offensive and defensive sides of security, from reverse-engineering stripped binaries with Ghidra and IDA Pro to achieving RCE via buffer overflow exploitation in CTF competitions. I've also built responsive frontend applications with Vue.js, JavaScript, and HTML/CSS, and presented research on code obfuscation resilience at a cybersecurity convention.

More recently, I've been building AI-Agent, a Python pipeline for tabular-data analysis and ML code generation. It uses Azure OpenAI to inspect datasets, produce structured feature-engineering recommendations (keep/scale/encode/drop/derive) grounded in domain context, local OpenML-style similarity, and summarized research-paper evidence — then generates, validates, and auto-retries training code with error feedback. Feature-set and model choices are scored under a shared cross-validation plan with preprocessing kept inside training folds to avoid leakage.

Before transitioning to tech, I served four years in the USMC as a Heavy Equipment Operator and Combat Marksmanship Coach, where I developed leadership, risk assessment, and precision under pressure — skills I now apply to solving complex technical problems.

Currently exploring: reverse engineering, malware analysis, and LLM-assisted machine learning pipelines.
